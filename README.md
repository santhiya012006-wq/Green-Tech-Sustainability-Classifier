# Green-Tech Sustainability Classifier 🌱

## 📌 About the Project

Green-Tech Sustainability Classifier is a machine learning application that classifies data related to sustainability and provides predictions through an interactive Streamlit web application.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Machine Learning

## ✨ Features

- Data preprocessing
- Machine learning classification
- Sustainability prediction
- Interactive Streamlit interface
- Easy-to-use web application
